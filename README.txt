# 🌤️ Weatherly — Modern Weather Dashboard

Weatherly is a modern, responsive weather dashboard built using **HTML, CSS, JavaScript, and Bootstrap**. It fetches real-time weather information using the **Open-Meteo API** and presents the data through a clean and user-friendly interface.

🔗 **Live Demo:**
https://gulfankhan79176-afk.github.io/Weatherly-App/

🔗 **GitHub Repository:**
https://github.com/gulfankhan79176-afk/Weatherly-App

---

## ✨ Features

* 🔍 Search weather by city
* 🌡️ Current temperature and feels-like temperature
* ☁️ Current weather condition
* 💧 Humidity information
* ☁️ Cloud cover
* 💨 Wind speed and direction
* 🌅 Sunrise and sunset
* 🌍 Automatic local timezone information
* 🏙️ Weather information for popular cities
* 📱 Responsive design for desktop and mobile
* ⚡ Loading and error handling
* 🎨 Modern and professional user interface

## 🌐 API

Weatherly uses the **Open-Meteo API** for weather information and geocoding.

### Geocoding API

Used to search for a city and obtain its coordinates.

```text
https://geocoding-api.open-meteo.com/v1/search
```

### Weather Forecast API

Used to retrieve weather information.

```text
https://api.open-meteo.com/v1/forecast
```

No API key is required for the current implementation.

## 🔎 How to Use

1. Open the Weatherly website.
2. Enter a city name in the search box.
3. Click the **Search** button.
4. Weatherly fetches the location and weather data.
5. View temperature, humidity, wind, sunrise, sunset, and other weather details.
6. Explore weather information for popular cities.
