# 🌤️ Weatherly – Weather Forecast Web App

Weatherly is a modern and responsive weather application that allows users to search for a city and view its current weather information in a simple and attractive interface.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Display current temperature
* ☁️ Show weather conditions
* 💧 Humidity information
* 💨 Wind speed information
* 📱 Responsive design for mobile and desktop
* 🎨 Modern and professional UI
* ⚡ Fast and easy to use
* 🌐 Real-time weather data using a weather API

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and API integration
* **Weather API** – Fetching real-time weather information

## 💻 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/weatherly.git
```

### 2. Open the Project

Go to the project folder:

```bash
cd weatherly
```

### 3. Run the Website

Open `index.html` in your browser.

You can also use **VS Code Live Server** to run the project.

If your project uses an API key, open `script.js` and add your API key according to the API provider's instructions.

Example:

```javascript
const API_KEY = "YOUR_API_KEY";
```

> ⚠️ Do not upload your real API key publicly to GitHub. Use environment variables or another secure method for production projects.

## 🎯 How It Works

1. Enter a city name in the search box.
2. Click the **Search** button.
3. JavaScript sends a request to the weather API.
4. The API returns the weather information.
5. Weatherly displays the result on the screen.
